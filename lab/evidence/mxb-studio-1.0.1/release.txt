# More tools in Free and faster editing on large tracks

Scatter, Array, Braking Bumps, Whoops, and primary heightmap import are back in Free\. This update also makes dense object scenes easier to edit and reduces exported centerline segments on long closed courses\.

- Changed \- Studio Free can create and edit Scatter, Array, Braking Bumps, and Whoops, and import or replace the primary heightmap\.
- New \- Scatter can place up to 20,000 objects in one pass\. It avoids occupied object centers and can keep clear of multiple selected track paths with a signed edge offset\. The preview explains when the requested count cannot fit\.
- New \- Use Preview on a new drawn or track\-linked Array to see the copies before applying\. Adjust the source, path, spacing, count, or scale and watch the preview update\. Apply commits the result in one Undo step\.
- Changed \- New Project opens directly to Generated landscape, Flat ground, or Import heightmap\. Existing projects keep their saved layout types\.
- Fixed \- Select trees by their visible foliage or trunk\. Clicking a gap between branches can now reach the object behind it, and the selection highlight follows the tree silhouette\.
- Fixed \- Placing or selecting models, creating groups, moving rows between groups, and expanding or collapsing large groups are faster in dense scenes\.
- Fixed \- Large projects can save up to 64 MiB of editable project metadata\. Use 1\.0\.1 or later to reopen saves that exceed the old limit\.
- Changed \- Closed courses longer than 2,500 meters can export with fewer centerline segments\.
- Fixed \- The folder button in Wear Paths opens the wear pattern library directly\.
