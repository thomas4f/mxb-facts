--| Installation |--

Put the discord_game_sdk.dll file in the game directory (SAME FOLDER AS MXBIKES.EXE)
This is important because the plugin requires it as a dependency and WILL NOT LOAD IF ITS NOT THERE!!

Put the discord-rpc.dlo file in the plugins folder

Once both steps are completed just launch the game and it will load
