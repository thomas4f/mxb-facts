What MX Bikes and GP Bikes tools do

MXB Facts looks at what community tools for MX Bikes and GP Bikes install, change and send, how they work with the game, and how much of them you can check. It doesn't review their features, usability or quality. Every tool gets the same questions and scoring rules, and each answer links its evidence.

Claude, an AI, does the analysis from a public prompt, and no person checks each answer, so one can be wrong. A score sums up the findings and what could be checked: a high score doesn't prove a tool is safe, and a low one doesn't prove it's harmful. Authors can run the same check on their own tool before a release, and correct anything a card gets wrong.

How it works

How a card is made

  1. A tool is requested through the request form, or Thomas picks it from mxb-mods.com. Requested tools come first, in the order asked; the pick is a choice, and the queue shows it.
  2. Its files are pinned: every file players download is hashed (SHA-256), and the release's commit is fixed when the source is public.
  3. The licence is read first. If it forbids analysis, only public facts are covered and the rest says "Not allowed".
  4. The AI analyses it from the published prompt: source or binaries, an offline run in a throwaway environment (a game plugin in the game's public demo, the rest in a test host; the card's Method row says what ran), and a VirusTotal lookup.
  5. Every question is answered with its evidence: a pinned code link, a file hash or a test anyone can repeat. What can't be proven or run goes under "Limits of this analysis", linked to the answers it affects.
  6. The build checks the card against the rules: it checks each answer's mark against the mark table, and sets every key-question mark, tag and score itself; nobody picks one of those by hand.
  7. Comments come in as issues: a correction, something missing, or the author's context. While one is open, the answers it names show its count, and nothing else changes. When one holds, the line is fixed and the card's history says what changed and why.
